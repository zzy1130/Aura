# 😤 用 ChatGPT 改论文的痛

- 贴一半就超 token 了
- 改完第三章，它忘了第一章
- 让它加引用，格式全乱

> 写论文的人都懂这种崩溃

---

# ✨ 我发现了 Vibe Coding

用 Cursor、Claude Code 边聊天边写代码，效率起飞！

于是我想：**能不能也这样写论文？**

试了 Claude Code 来「vibe write」

确实强，但全是命令行...

---

# 🤔 问题来了

👨‍💻 全是终端、代码、命令行

👨‍💻 要会 git、会配环境

👨‍💻 文科/医学/社科朋友完全看不懂

**凭什么只有程序员能用最先进的 AI 工具？**

---

# 🔬 于是我做了 YouResearch

把 Claude Code 的能力，包进正常人能用的界面：

- 📝 左边写 LaTeX
- 💬 右边跟 AI 聊天
- 📄 下面实时看 PDF

**不用开终端，像用 Word 一样自然**

---

# 📚 超简单的用法

**/research 你的方向**
→ 自动搜 arXiv、Google Scholar
→ 总结每篇在讲什么

**/vibe 你的方向**
→ 自动发现研究空白
→ 生成研究假设

**选中文字 → 右键 Polish**
→ 帮你改得更学术地道

---

# 🔒 本地运行 = 隐私安全

你的论文、你的 idea
**不会上传到任何服务器**

上周 OpenAI 发了 Prism
功能类似，但那是云端的

研究者应该有选择权
所以我决定**开源**
