# 小红书笔记素材

## 📌 标题（不超过20字）

**用ChatGPT改论文太痛苦？我做了个工具**

## 📝 正文

用ChatGPT改论文，我真的受够了 😤

去年写毕业论文的时候，天真地把整个 tex 文件丢给 ChatGPT。结果：
- 贴一半就超 token 了
- 改完第三章，它忘了第一章写的啥
- 让它帮我加引用，格式全乱了

后来接触到「vibe coding」——用 Cursor、Claude Code 这些工具边聊天边写代码。我想：能不能也这样写论文？

于是我试了用 Claude Code 来「vibe write」✍️

确实强，但问题来了：全是命令行和终端，要会 git、会配环境。我一个搞 AI 的还行，我那些文科/医学/社科的朋友完全看不懂。

**这不公平。凭什么只有程序员能用最先进的 AI 工具？**

所以我自己 vibe code 了一个：**YouResearch** 🔬

把 Claude Code 的能力，包进一个正常人能用的界面里：
- 左边写 LaTeX
- 右边跟 AI 聊天
- 下面实时看 PDF

📚 **用法超简单**：

**搜论文**：打 `/research 你的方向`，自动搜 arXiv、Google Scholar，总结每篇在讲什么

**Vibe 模式**：打 `/vibe 你的方向`，去喝杯咖啡 ☕ 回来它告诉你领域有哪些主流方法、研究空白在哪、你可以往哪挖

**润色写作**：选中一段蹩脚英文，右键 Polish，帮你改得更学术更地道

**修复报错**：LaTeX 报错不用怕，它直接告诉你「第47行少了括号，我帮你加上了」

🔒 **最重要的**：完全本地运行，你的论文和 idea 不会上传到任何服务器

上周 OpenAI 发了 Prism，功能类似但那是云端的。我觉得研究者应该有选择权，所以赶紧开源了。

macOS 可直接下载，完全免费 🍎
